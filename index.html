02 / Weitere Browser-Daten

Dein digitales Geräteprofil

Diese Angaben kann eine besuchte Website je nach Browser auslesen. Es sind keine geheimen Daten, aber sie können helfen, Geräte voneinander zu unterscheiden.

Einige Browser verbergen oder vereinheitlichen solche Angaben absichtlich. „Nicht verfügbar“ bedeutet nicht, dass du etwas falsch gemacht hast.
03 / Berechtigungen

Was darf eine Website?

Wir fragen den Browser nach dem aktuellen Berechtigungsstatus. Dabei wird keine Kamera, kein Mikrofon und kein Standort aktiviert. Eine Website muss für solche Zugriffe normalerweise erst deine Erlaubnis bekommen.

Berechtigungen werden geprüft…

Die Anzeige hängt vom Browser ab. Manche Berechtigungen werden nicht unterstützt oder erst nach einer konkreten Anfrage angezeigt.

04 / Was ändert sich nach dem Login?

Ein Konto ist ein ganz anderes Level.

Vor der Anmeldung kennt eine Website oft nur technische Signale und das, was du auf der Seite tust. Nach der Anmeldung kann sie diese Informationen mit einem Konto verbinden. Dadurch entsteht ein viel genaueres Bild.

01 / IDENTITÄT

Name und E-Mail

Wenn du sie angibst oder freigibst, kann der Dienst Aktivitäten deinem Konto zuordnen. Eine E-Mail-Adresse kann auch auf anderen Diensten als Wiedererkennungsmerkmal dienen.

02 / VERHALTEN

Deine Nutzung

Suchanfragen, angesehene Inhalte, Klicks, Käufe, gespeicherte Einstellungen und Nutzungszeiten können mit deinem Konto verknüpft werden.

03 / VERKNÜPFUNG

Mehrere Geräte

Wenn du auf Handy, Tablet und Computer angemeldet bist, kann ein Anbieter Aktivitäten möglicherweise demselben Konto zuordnen.

Beispiel: „Mit Google anmelden“

Was bekommt eine Website von Google?

Bei einer normalen Google-Anmeldung werden typischerweise die ausdrücklich angeforderten Basisdaten freigegeben. Welche Daten genau fließen, steht im Google-Freigabefenster. Eine Anmeldung bedeutet nicht automatisch Zugriff auf dein ganzes Google-Konto.

Basisprofil

Je nach Anmeldung: Name, E-Mail-Adresse, Profilbild und eine Kennung, mit der der Dienst dein Google-Konto wiedererkennt.

Kontakte

Nur wenn eine App zusätzlich den Zugriff auf Kontakte anfordert und du ihn erlaubst. Die normale Anmeldung reicht dafür nicht.

Google Drive

Dateien können nur im Umfang der erteilten Berechtigung zugänglich sein. Lies genau, ob eine App einzelne Dateien oder breiteren Zugriff verlangt.

Kalender

Termine und Kalenderdaten benötigen eine eigene Berechtigung. Eine Website sollte nicht mehr Zugriff bekommen, als sie wirklich braucht.

Wichtig: Google zeigt vor der Freigabe an, welche Berechtigungen eine App verlangt. Wenn eine einfache Taschenlampen-App Zugriff auf deine Dateien oder Kontakte will, ist das ein ziemlich guter Grund, abzubrechen.

Was gibst du bei einer Anmeldung preis?

Markiere, welche Angaben ein Dienst von dir verlangt. Bitte trage hier keine echten persönlichen Daten ein.

Wähle die Daten aus, die ein Anmeldeformular verlangt. Dann erklären wir, wie viel daraus entstehen kann.
05 / Was man kombinieren kann

Einzelne Daten wirken harmlos. Zusammen nicht unbedingt.

NETZWERK

IP + Uhrzeit

Kann helfen, einen Besuch einem Anschluss oder einer ungefähren Region zuzuordnen. Eine IP ist nicht automatisch eine eindeutige Personen-ID.

FINGERABDRUCK

Browser + Gerät

Viele technische Merkmale können zusammen einen wiedererkennbaren Browser-Fingerabdruck ergeben. Das ist keine perfekte oder sichere Identifikation.

KONTO

E-Mail + Verhalten

Wenn ein Dienst deine E-Mail kennt, kann er Aktivitäten im eigenen Angebot einem Konto zuordnen und über längere Zeit auswerten.

07 / Grenzen

Was eine Website nicht einfach so sehen kann

Eine normale Website kann nicht einfach deine Passwörter, privaten Fotos, Nachrichten, Kontakte oder Dateien lesen. Auch deinen genauen GPS-Standort bekommt sie normalerweise nicht ohne Berechtigung. Dafür müsste sie deine Daten von dir erhalten, eine Berechtigung bekommen oder eine Sicherheitslücke ausnutzen. Diese Seite macht keine heimlichen Zugriffe und fordert keine Geräteberechtigungen an.
